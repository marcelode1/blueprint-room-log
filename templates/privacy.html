Privacy Policy

Effective Date: May 2026

ProjectONus (“we”, “our”, or “us”) provides project management, room documentation, communication, photo storage, audio notes, and collaboration tools for contractors, employees, and customers.

Information We Collect

ProjectONus may collect:

  • User account information
  • Project information
  • Customer information
  • Photos uploaded by users
  • Audio recordings uploaded by users
  • Comments and room notes
  • Device/browser information required for app functionality

How Information Is Used

Information is used only for:

  • Project management
  • Team collaboration
  • Customer communication
  • Field documentation
  • Internal reporting
  • System security and permissions

We do not sell personal information.

Storage

Files and project data may be stored using secure third-party cloud providers, including Render and Supabase.

Permissions

Project administrators may control:

  • User permissions
  • Access to comments
  • Access to photos
  • Access to audio
  • Project visibility

Mobile Features

The mobile app may request access to:

  • Camera
  • File storage
  • Microphone

These permissions are used only for app functionality.

Security

We take reasonable measures to protect user information and project data.

SMS / Text Messaging

{{ get_app_setting("company_name", "ProjectONus") }} uses SMS text messaging to communicate with workers, subcontractors, and customers about active projects. A phone number is added to our system in one of two ways:

  • A worker or customer taps a project invite link, and submits their own name and phone number to create their account.
  • An administrator manually adds a team member's phone number when setting up their account.

Opt-in language shown at the point of collection:

"By submitting my phone number, I agree to receive SMS text messages from {{ get_app_setting("company_name", "ProjectONus") }} related to my project and account, such as account setup links and technician dispatch/arrival updates. Message and data rates may apply. Message frequency varies. Reply STOP to opt out at any time, or HELP for help."

Types of messages sent:

  • Account setup / login links when someone is invited to a project
  • Technician dispatch and arrival-time updates for a scheduled visit
  • Other project-related updates from an administrator or team member

We do not send marketing messages, and we do not sell or share phone numbers with third parties. Message and data rates may apply. Message frequency varies based on project activity. Reply STOP to a message at any time to opt out, or HELP for help.
